Using the mark

Rules that keep it recognisable

A mark that changes shape every time it appears has to be re-learned every time. For an audience that recognises the picture before the word, consistency is not fussiness — it is the whole mechanism.

Clear space = the height of the counter bar
Makola.io

Nothing enters the dashed box — not a nav item, not a photo edge, not another logo. Measure it off the counter bar so it scales with the mark instead of being a fixed pixel number.

Smallest it may go
Makola.io
Full lockup · 120 px wide
Mark alone · 24 px
Favicon · 16 px

Below 24 px the scalloped hem fills in. Use the simplified favicon cut — one canopy, one bar, no shadow — never a shrunk copy of the full mark.

✕ Never

Stretch or squash it. Scale both sides together.

✕ Never

Recolour it. Gold and ink, or one flat colour.

✕ Never

Drop it onto a busy photo. Add an ink scrim first.

✕ Never

Rotate it or add a shadow, bevel or glow.
